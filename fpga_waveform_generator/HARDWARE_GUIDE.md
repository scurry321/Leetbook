# 🔧 FPGA 波形发生器 — 硬件下板 & 示波器显示 完整指南

> **你已经仿真成功了（或不想仿真了），现在要把设计下载到 FPGA 实验箱，用示波器看到真实波形。**
> 本指南将手把手带你走完从 Quartus 编译到示波器显示的全过程。

---

## 📋 你需要准备什么

| 物品 | 说明 |
|------|------|
| FPGA 实验箱 | 通常带 Cyclone IV (EP4CE6/10/15) 或类似 FPGA |
| USB-Blaster 下载线 | 连接电脑和实验箱（通常实验箱自带） |
| 示波器 | 任何能显示 1-20 kHz 信号的示波器 |
| 示波器探头 | BNC 线缆或探头 |
| DAC 模块 | 实验箱自带的 DAC（如 DAC0832）或外接 R-2R 电阻网络 |
| Quartus 18.0 | 已安装在你的电脑上 |

## 第 1 步：创建 Quartus 工程

> 如果你已经有工程了，可以直接用已有的工程，跳到第 2 步。

### 新建工程

1. 打开 **Quartus 18.0**
2. 菜单：**File** → **New Project Wizard...**
3. 按照向导填写：
   - **工程目录**：选一个你喜欢的文件夹，例如 `D:\FPGA_DDS\`
   - **工程名称**：`waveform_gen`
   - **顶层实体名称**：`waveform_gen_top`
4. **器件选择**：选择你实验箱上的 FPGA 型号
   - 常见型号：
     - `EP4CE6E22C8` (Cyclone IV，小型板)
     - `EP4CE10E22C8` (Cyclone IV，中型板)
     - `EP4CE15F17C8` (Cyclone IV，较大型板)
   - **不知道型号怎么办？**
     - 看实验箱上 FPGA 芯片表面的丝印
     - 或查看实验箱的说明书/原理图
5. 点击 **Finish** 完成

## 第 4 步：分配引脚 ⭐（最重要的一步）

> **这一步决定了 FPGA 的哪些物理引脚连接到你实验箱上的哪些硬件。**
> 引脚分配错误会导致：没有输出、输出到错误的位置、甚至可能损坏器件。

### 方法 A：使用引脚分配编辑器（推荐新手）

1. 菜单：**Assignments** → **Pin Planner**
2. 在底部的表格中，你会看到所有未分配的引脚（所有信号名）
3. 在 **Location** 列中，为每个信号填入正确的引脚编号

### 你需要分配的信号

下面是所有需要分配的信号及其含义。**引脚号必须根据你自己的实验箱来确定！**

#### 🔵 必须分配的信号

| 信号名 | 方向 | 连接到实验箱的 | 怎么找到引脚号 |
|--------|------|--------------|--------------|
| `CLK_50M` | 输入 | 50 MHz 晶振 | 看原理图中晶振连接的 FPGA 引脚 |
| `RST_N` | 输入 | 复位按钮 | 看原理图中按钮连到的引脚 |
| `SW_WAVE[1:0]` | 输入 | 两个拨码开关 | 看原理图中开关连到的引脚 |
| `KEY_FREQ_UP` | 输入 | 按钮 (频率+) | 看原理图中按钮连到的引脚 |
| `KEY_FREQ_DOWN` | 输入 | 按钮 (频率-) | 看原理图中按钮连到的引脚 |
| `DAC_DATA[7:0]` | 输出 | DAC 数据引脚 | 看原理图中 DAC 的 D0~D7 连到的引脚 |

#### 🟡 建议分配的信号

| 信号名 | 方向 | 连接到实验箱的 | 说明 |
|--------|------|--------------|------|
| `KEY_AMP_UP` | 输入 | 按钮 (幅度+) | 不用可以连到 VCC (3.3V) |
| `KEY_AMP_DOWN` | 输入 | 按钮 (幅度-) | 不用可以连到 VCC (3.3V) |
| `DAC_WR_N` | 输出 | DAC 的 /WR 引脚 | DAC0832 需要，R-2R 不需要 |
| `LED_SINE` | 输出 | LED 指示灯 | 可选，帮助你确认当前波形 |
| `LED_TRI` | 输出 | LED 指示灯 | 可选 |
| `LED_SQR` | 输出 | LED 指示灯 | 可选 |
| `LED_FREQ[3:0]` | 输出 | 4 个 LED | 可选，显示频率档位 |

#### 🔘 可以不分配的信号

| 信号名 | 说明 |
|--------|------|
| `DAC_DATA_12[11:0]` | 12 位 DAC 输出，如果你只用 8 位 DAC，不需要分配 |

### 方法 B：使用 Tcl 脚本分配引脚（快速）

1. 打开 `hw/pin_assignment_example.tcl`
2. **修改里面的引脚编号**，改成你自己实验箱的引脚
3. 在 Quartus 中：菜单 **Tools** → **Tcl Scripts...**
4. 选择此脚本，点击 **Run**

### ❓ 怎么知道自己实验箱的引脚号？

1. **查看实验箱原理图**（最准确）
   - 找到 "FPGA 引脚分配表" 或 "Pin Map"
   - 找到你要用的硬件（按钮、开关、LED、DAC）对应的 FPGA 引脚号
   
2. **查看实验箱用户手册**
   - 通常会列出所有外设与 FPGA 引脚的对应关系

3. **查看板子上的丝印**
   - 有些板子在按钮/开关旁边标注了引脚号

4. **常见 Cyclone IV 开发板引脚参考**（仅供参考，以你的板子为准）：

   | 外设 | 常见引脚 (仅参考!) |
   |------|------------------|
   | 50 MHz 晶振 | PIN_23 或 PIN_91 |
   | KEY0 (按钮) | PIN_88 或 PIN_25 |
   | KEY1 (按钮) | PIN_89 或 PIN_24 |
   | KEY2 (按钮) | PIN_90 |
   | KEY3 (按钮) | PIN_91 |
   | SW0 (拨码开关) | PIN_88 |
   | SW1 (拨码开关) | PIN_89 |
   | LED0 | PIN_72 或 PIN_85 |
   | LED1 | PIN_73 或 PIN_84 |
   | LED2 | PIN_74 或 PIN_83 |
   | LED3 | PIN_75 或 PIN_82 |

   > ⚠️ **以上引脚号仅为参考示例！不同厂家的板子引脚完全不同！一定要看你自己的原理图！**

### 不需要的引脚怎么处理？

如果有些信号你不想用（比如 `DAC_DATA_12` 或 `LED_FREQ`），有两种处理方式：

**方式 1：在 Quartus 中设置未使用引脚为三态**（推荐）
1. 菜单：**Assignments** → **Device...**
2. 点击 **Device and Pin Options...**
3. 在 **Unused Pins** 选项卡中，选择 **As input tri-stated**
4. 点击 **OK**

**方式 2：修改 VHDL 代码去掉不需要的端口**
- 在 `waveform_gen_top.vhd` 中注释掉不需要的端口声明和相关逻辑

1. 菜单：**Processing** → **Start Compilation**
   - 或者按快捷键 **Ctrl + L**
   - 或者点击工具栏上的 ▶️ 按钮
2. 等待编译完成（通常 1-3 分钟）
3. 检查编译结果：
   - ✅ **0 Errors** → 编译成功！
   - ⚠️ **有 Warnings** → 通常可以忽略（如未使用引脚警告）
   - ❌ **有 Errors** → 需要修复，参见下面的常见错误

### 常见编译错误

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| `Can't find design unit "work.sine_lut"` | 缺少 `sine_lut.vhd` | 确认已添加此文件到工程 |

## 第 7 步：接线 + 用示波器看波形 🎉

### 7.1 确认 FPGA 已正常工作

下载成功后，观察实验箱上的 LED：

| 你应该看到 | 含义 |
|-----------|------|
| `LED_SINE` 亮 | 当前输出正弦波（默认） |
| `LED_FREQ` 显示二进制 0111 (十进制 7) | 默认频率档 7 = 10 kHz |

如果 LED 不亮，检查引脚分配是否正确。

### 7.2 DAC 接线

你的 DAC 接线方式取决于实验箱上 DAC 的类型：

#### 情况 A：实验箱自带 DAC0832

大多数 FPGA 实验箱都有板载 DAC0832 模块。接线方式：

```
FPGA 引脚                    DAC0832
─────────────────────────────────────
DAC_DATA[7] ──────────────→  D7 (MSB)
DAC_DATA[6] ──────────────→  D6
DAC_DATA[5] ──────────────→  D5
DAC_DATA[4] ──────────────→  D4
DAC_DATA[3] ──────────────→  D3
DAC_DATA[2] ──────────────→  D2
DAC_DATA[1] ──────────────→  D1
DAC_DATA[0] ──────────────→  D0 (LSB)
DAC_WR_N    ──────────────→  /WR
                              /CS  ── 接 GND (片选始终有效)
                              XFER ── 接 GND (直通模式)
                              Iout ── 接运算放大器转电压
                              Vref ── 接参考电压 (如 5V)
```

> **如果实验箱上 DAC 已经和 FPGA 连好了**（很多实验箱都是这样），
> 你只需要在引脚分配时，把 `DAC_DATA[0..7]` 分配到板上标注的 DAC 数据引脚就行。
> 然后找到 DAC 的模拟输出端，接示波器探头。

#### 情况 B：使用 R-2R 电阻网络 DAC

如果实验箱提供的是 R-2R 电阻梯形网络：

```
DAC_DATA[7] ──┬── 20kΩ ──┐
              R(10kΩ)     │
DAC_DATA[6] ──┬── 20kΩ ──┤
              R(10kΩ)     │
DAC_DATA[5] ──┬── 20kΩ ──┤
              R(10kΩ)     │    Vout ──→ 示波器
 ...          ...         │
DAC_DATA[0] ──┬── 20kΩ ──┘
              R(10kΩ)
              │
             GND
```

> R-2R 网络不需要 `DAC_WR_N` 信号，输出是连续的模拟电压。

#### 情况 C：使用 GPIO 排针外接 DAC

如果实验箱没有板载 DAC，你可以：
1. 把 `DAC_DATA[0..7]` 连到 GPIO 排针
2. 用杜邦线连接到外部 DAC 模块
3. DAC 模块的模拟输出连到示波器

### 7.3 连接示波器

1. 把示波器探头连接到 **DAC 的模拟输出端**
2. 示波器探头的**地线夹**连接到电路板的 **GND**（非常重要！）
3. 设置示波器：
   - **时基 (Time/Div)**：先设为 **50 µs/div**（适合 10 kHz）
   - **电压 (Volts/Div)**：先设为 **1 V/div**
   - **触发方式**：**自动 (Auto)**
   - **耦合方式**：**DC** 或 **AC**

### 7.4 调整示波器看到清晰波形

上电后你应该能看到波形。如果看不到：

| 问题 | 检查 |
|------|------|
| 一条直线 | 检查 DAC 接线；电压量程可能太大，调小 V/div |
| 完全没有信号 | 检查示波器地线夹是否连接；检查探头是否连对 |
| 波形很小 | 调小 V/div（如 100 mV/div） |
| 波形频率不对 | 调整 Time/div |
| 很多噪声 | 接线尽量短；确保地线连接良好 |

### 7.5 操作实验箱控制波形

| 操作 | 效果 |
|------|------|
| 拨 `SW_WAVE` 开关到 `00` | 切换到正弦波 |
| 拨 `SW_WAVE` 开关到 `01` | 切换到三角波 |
| 拨 `SW_WAVE` 开关到 `10` | 切换到方波 |
| 按 `KEY_FREQ_UP` | 频率升一档 |
| 按 `KEY_FREQ_DOWN` | 频率降一档 |
| 按 `KEY_AMP_UP` | 幅度增大 |
| 按 `KEY_AMP_DOWN` | 幅度减小 |

### 频率档位对照表

| 档位 | LED_FREQ 显示 | 频率 | 示波器 Time/div 建议 |
|------|--------------|------|---------------------|
| 0 | 0000 | 1 kHz | 200 µs/div |
| 1 | 0001 | 2 kHz | 100 µs/div |
| 2 | 0010 | 3 kHz | 100 µs/div |
| 3 | 0011 | 4 kHz | 50 µs/div |
| 4 | 0100 | 5 kHz | 50 µs/div |
| 5 | 0101 | 6 kHz | 50 µs/div |
| 6 | 0110 | 8 kHz | 20 µs/div |
| **7** | **0111** | **10 kHz (默认)** | **20 µs/div** |
| 8 | 1000 | 15 kHz | 20 µs/div |
| 9 | 1001 | 20 kHz | 10 µs/div |

## 常见问题 FAQ

### Q1：编译成功，下载成功，但示波器上看不到波形

**可能原因和检查清单：**

1. ✅ 检查引脚分配是否正确（最常见的问题！）
2. ✅ 检查示波器探头是否连接到 DAC 的模拟输出（不是数字引脚）
3. ✅ 检查示波器地线夹是否连接到 GND
4. ✅ 检查 DAC 是否有供电（DAC0832 需要 +5V 电源）
5. ✅ 调整示波器的电压灵敏度（尝试 100 mV/div ~ 5 V/div）
6. ✅ 检查复位按钮是否松开（RST_N 应该为高电平）

### Q2：波形是阶梯状的，不光滑

**正常现象！** 8 位 DAC 只有 256 个电压等级，正弦波会有轻微阶梯。

**改善方法：**
- 在 DAC 输出后加一个低通滤波器（RC 滤波器）
- 例如：串联一个 1kΩ 电阻，再并联一个 10nF 电容到地
- 截止频率 ≈ 1/(2π×1kΩ×10nF) ≈ 16 kHz

```
DAC 输出 ──── 1kΩ ────┬──── 到示波器
                       │
                     10nF
                       │
                      GND
```

### Q3：波形的幅度很小

DAC0832 的输出电流需要运算放大器转换为电压。

- 如果实验箱有配套的运放电路，直接用运放输出端
- 如果没有，DAC0832 的 Iout 输出电流约 0~2 mA
- 通过外接运放（如 LM358）可以放大到任意幅度

### Q4：方波可以看到，但正弦波/三角波不正常

- 方波只需要 MSB（最高位），所以只要 D7 引脚正确就能看到
- 正弦波和三角波需要所有 8 位数据都正确
- 检查 `DAC_DATA[0]` 到 `DAC_DATA[7]` 的引脚分配是否都正确
- 检查数据线是否有松动或断开

### Q5：频率不准确

- 确认你的实验箱上的晶振确实是 50 MHz
- 如果是其他频率（如 25 MHz），需要修改代码中的频率控制字
- FTW 计算公式：`FTW = f_out × 2^32 / f_clk`

### Q6：按钮按下去没反应

- 确认按钮引脚分配正确
- 确认按钮是低电平有效（按下为 0）
- 如果你的板子按钮是高电平有效，需要修改 `key_debounce.vhd` 中的逻辑

### Q7：我的实验箱时钟不是 50 MHz

如果你的板子时钟频率不同（比如 25 MHz 或 100 MHz），需要修改两处：

1. **`key_debounce.vhd`**：修改 generic 中的 `CLK_FREQ`
2. **频率控制字**：重新计算 FTW
   - 公式：`FTW = round(f_out × 2^32 / f_clk)`
   - 例如 25 MHz 时钟下，10 kHz 的 FTW = `round(10000 × 4294967296 / 25000000)` = 1717987

### Q8：我只想固定输出一个波形，不要按钮控制

你可以简化顶层模块。修改 `waveform_gen_top.vhd`，直接固定频率和波形选择：

```vhdl
-- 固定为 10 kHz 正弦波，满幅度
freq_word <= x"000D1B71";   -- 10 kHz
wave_sel  <= "00";           -- 正弦波
amp_ctrl  <= x"FF";          -- 满幅度
```

然后你就不需要按钮和开关了，只需要分配 CLK_50M、RST_N 和 DAC_DATA 引脚。

### Q9: 怎么不通过按钮，而是用拨码开关来选择频率？

你可以用 4 个拨码开关替代频率按钮。修改 `waveform_gen_top.vhd`：

```vhdl
-- 声明新端口
SW_FREQ : in std_logic_vector(3 downto 0);  -- 4 个拨码开关选频率

-- 在 architecture 中用开关值直接索引频率表
freq_level <= to_integer(unsigned(SW_FREQ))
              when to_integer(unsigned(SW_FREQ)) <= 9
              else 9;
```
